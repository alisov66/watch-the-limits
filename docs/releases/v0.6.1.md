Restores the collapsible-section animation from the approved Figma design.

## Fixed

- **Settings** and **Available resets** now expand and collapse with **300 ms ease-out** transitions.
- Disclosure arrows rotate with the same timing, and the native panel follows the animated content height while keeping its top edge anchored.
- Rapidly reversing a section transition settles at the correct size.
- **Reduce Motion** skips the section and arrow animations. Collapsed content remains unavailable to pointer interaction and accessibility.

## Install or update

1. Quit the running copy of **Watch the Limits**.
2. Download **Watch-the-Limits-macOS.zip** from Assets below and unzip it.
3. Move **Watch the Limits.app** to Applications, replacing the previous copy, then open it.

Requires **macOS 13 or newer**. The download supports **Apple Silicon and Intel**. Native Liquid Glass is used on macOS 26 and later.

This release is ad-hoc signed and is not notarized by Apple. If macOS blocks it, review the release and use **System Settings → Privacy & Security → Open Anyway**, when available.
